# BlueBottleCap AI Suite

This is the primary Next.js application for the BlueBottleCap SaaS platform. It encompasses our advanced AI tools, authentication via Supabase, and a responsive modern user interface built with Tailwind CSS.

## Getting Started

1. Install dependencies:
   ```sh
   npm install
   ```

2. Set up your environment variables:
   Copy `.env.example` to `.env.local` and add your required API keys (Gemini, Supabase, Razorpay).

3. Run the development server locally:
   ```sh
   npm run dev
   ```

For more details on the entire platform, please see the [root README](../README.md).
